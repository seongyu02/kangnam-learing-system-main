# 중간고사 안내

**[학생용 사용 가이드](../학생용-사용가이드.md)** 에서 자료 학습부터 두 단계 모의시험과 오답 복습까지 진행하는 방법을 확인하세요.

두 팀 모두 지정된 두 로드맵의 **Phase 1~5(Phase 5 포함)**가 중간고사 범위다.

| 팀 | 중간고사 범위 |
|---|---|
| [네트워크 01 중간고사](%EB%84%A4%ED%8A%B8%EC%9B%8C%ED%81%AC%2001%20%EC%A4%91%EA%B0%84%EA%B3%A0%EC%82%AC/README.md) | AI 네이티브 회사 로드맵 + DB 설계 로드맵, 각각 Phase 1~5 |
| [네트워크 02 중간고사](%EB%84%A4%ED%8A%B8%EC%9B%8C%ED%81%AC%2002%20%EC%A4%91%EA%B0%84%EA%B3%A0%EC%82%AC/README.md) | 네트워크 서비스 로드맵 + DB 설계 로드맵, 각각 Phase 1~5 |

두 팀 공통으로 **3~6주차 수업 내용**([공통 체크리스트](%EA%B3%B5%ED%86%B5%203~6%EC%A3%BC%EC%B0%A8%20%EC%88%98%EC%97%85/README.md))도 범위다. 주차별 핵심 개념과 이에 대응하는 PM 로드맵 핵심 강의를 모았다.

**모의시험**: `/midterm-concept 01` 또는 `/midterm-concept 02` 로 30문제를 푼다. 문제가 개념을 설명하고, 이해했는지 서술형(이유·적용·구별)으로 묻는다. 기록은 `내학습/모의고사.md` 에 남는다.

저장소에는 시험 범위의 로드맵(Phase 1~5)과, 이 폴더의 체크리스트에 있는 강의만 남겨 두었다.
