# 공통 — 3~6주차 수업

## 범위

01·02 팀 **모두** 3~6주차 수업 내용을 함께 본다. 수업은 한 제품을 따라 **왜 → 확인 → 무엇 → 어떻게** 순서로 진행됐다. 아래는 주차별 핵심 개념마다 같은 내용을 다루는 PM 강의를 하나씩 붙인 체크리스트다.

강의를 읽고 옆에 적힌 핵심을 자료 없이 설명할 수 있으면 `[x]`로 표시한다.
