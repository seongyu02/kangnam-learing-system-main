# 복습큐

틀린 것만 들어온다. 맞은 것은 넣지 않는다.

복습 간격: **1일 → 3일 → 7일 → 16일 → 35일**
복습해서 맞히면 다음 칸으로, 틀리면 1일로 되돌린다.

| 항목 | 주제 | 처음 틀린 날 | 다음 복습일 | 상태 |
|---|---|---|---|---|
| 숫자로 된 식별값의 원래 표기를 보존하는 이유 | DB 설계 Phase 1 | 2026-10-12 | 2026-10-13 | 1회차 · 당일 교정: 앞의 0 보존을 설명함. 다른 식별값 사례로 재확인 |
| 중복 이름을 식별·연결 기준으로 쓰면 안 되는 이유 | DB 설계 Phase 1 | 2026-10-12 | 2026-10-13 | 1회차 · 이름의 유일성·불변성 주장 교정 후 회원번호 연결을 답함. 동명이인 확인 필요성은 학생이 처음부터 언급했음 |
| 분리한 납부 기록 테이블에 회원번호를 남기는 이유 | DB 설계 Phase 1·3 | 2026-10-12 | 2026-10-13 | 1회차 · 납부번호·납부금액만 적어 회원번호 누락. 연결 속성을 직접 다시 구성해야 함 |
| 엔티티와 식별자 속성의 구별 | DB 설계 Phase 2 | 2026-10-12 | 2026-10-13 | 1회차 · 학번을 엔티티로 분류했다가 교정. 직원번호는 식별자 속성으로 맞힘 |

당일 교정은 간격 복습 성공으로 계산하지 않는다. 예정일에 다른 사례로 다시 답한 결과에 따라 다음 간격을 정한다.
