### 기록·진도 처리

- 사용자 요청에 따라 이후 기록은 학습 마무리 시 모아서 저장한다.
- 속도: 이미 맞힌 기초의 반복을 줄이고 핵심 설명 → 조건이 명확한 문제 하나 → 채점으로 진행한다.
- 사례: 원문 사례 중심으로 진행하며 변형 사례는 명시한다.
- 자료 학습 중이며 개념·AI 요청 모의시험에는 아직 응시하지 않았다.
- Phase 1·2 전체 완료로 처리하지 않았다. 실습 산출물 및 아직 확인하지 않은 항목은 미완료로 유지한다.
- 사용자의 float 발언은 숫자 자료형의 예시였다고 정정했으므로 “모든 숫자는 float”라는 오개념으로 기록하지 않는다.
- 최종 세 줄 요약은 아직 받지 않았다. 사용자가 작성하면 이 기록에 추가한다.
- 현재 프로젝트에서 `git status --short` 실행 결과 Git 저장소가 아니라고 확인되어 커밋은 수행하지 않았다.
